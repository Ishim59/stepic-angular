Демонстрация встроенных пайпов в Angular

Date Pipe

Текущее время (по умолчанию): {{ dateValue | date }}

Форматированная дата (dd.MM.yyyy HH:mm): {{ dateValue | date: 'dd.MM.yyyy HH:mm' }}

Case Pipes

Исходный текст: {{ text }}

UpperCase: {{ text | uppercase }}

LowerCase: {{ text | lowercase }}

TitleCase: {{ text | titlecase }}

Slice Pipe

Массив: {{ items }}

Срез (c 1 по 3 элемент): {{ items | slice:1:3 }}

Number Pipe

Число: {{ amount }}

Форматированное число (1.2-2): {{ amount | number:'1.2-2' }}

Currency Pipe

Сумма: {{ amount }}

Валюта (RUB): {{ amount | currency:'RUB':'symbol':'1.2-2' }}

Percent Pipe

Доля: {{ percentage }}

Формат (1.2-2): {{ percentage | percent:'1.2-2' }}

JSON Pipe

Объект user:

{{ user | json }}

Slice Pipe на длинном тексте

Исходный текст:

{{ longText }}

Укороченный (первые 50 символов):

{{ longText | slice:0:50 }}...
